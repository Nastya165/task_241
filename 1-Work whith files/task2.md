# Отчет по практическому занятию: Перенаправление потоков и конвейеры

## 1. Как работают операторы `>` и `>>`?

Оператор `>` перенаправляет стандартный вывод команды в файл, **перезаписывая** его. Если файл существует, его старое содержимое стирается. Оператор `>>` **дописывает** вывод в конец файла, сохраняя старое содержимое.

Сначала создается отдельная папка redirect_test с помощью команды mkdir -p, чтобы не засорять домашнюю директорию, и осуществляется переход в нее командой cd. Затем команда echo "Строка 1" > test.txt создает файл test.txt и записывает в него первую строку (символ > перезаписывает файл). Следующая команда echo "Строка 2" >> test.txt дописывает вторую строку в конец файла (символ >> добавляет данные, не удаляя старые). В завершение команда cat test.txt выводит итоговое содержимое файла на экран.

## 2. Что такое стандартные потоки stdin, stdout, stderr?

У каждой программы по умолчанию есть три канала связи (файловых дескриптора):

stdin (дескриптор 0) — стандартный ввод. Сюда программа получает данные (по умолчанию с клавиатуры).
stdout (дескриптор 1) — стандартный вывод. Сюда программа пишет результаты своей успешной работы (по умолчанию на экран).
stderr (дескриптор 2) — стандартный вывод ошибок. Сюда программа пишет сообщения об ошибках (по умолчанию на экран).
Разделение этих потоков позволяет фильтровать информацию. Например, сохранять полезные данные в один файл, а ошибки — в другой, или скрывать ошибки, не затрагивая основной вывод.

## 3 Вывести содержимое файла, не используя текстовые редакторы.

Для этого используется команда cat. Она читает файл и выводит его содержимое на экран.

Команда cat (concatenate) читает файл test.txt и выводит его содержимое в стандартный поток вывода (stdout). Этот способ удобен для быстрого просмотра небольших файлов, так как не требует открытия тяжелых текстовых редакторов вроде vim или nano.

## 4 Создать файл с содержимым, не используя текстовый редактор.

Это можно сделать с помощью команды echo и оператора перенаправления >.

 Команда echo выводит указанный текст в стандартный поток. Символ > перенаправляет этот вывод в файл my_file.txt. Если файл не существовал, он будет создан. Если существовал — его содержимое будет перезаписано новым текстом.

## 6 Чем отличаются `stdout` и `stderr`?
 stdout (дескриптор 1) предназначен для вывода полезных данных (результатов работы программы). stderr (дескриптор 2) предназначен для вывода сообщений об ошибках и предупреждений. Они независимы: можно перенаправить результаты в файл, а ошибки оставить на экране (или наоборот). Также stderr обычно не буферизуется, чтобы ошибка отображалась мгновенно.
