# Работа в консоли

1) Переместиться между директориями.
2) Вывести список файлов в директории.
3) Вывести список всех файлов, включая скрытые.
4) Создать папку с несколькими уровнями подпапок.
5) Внутри папки создать файл и записать в него несколько строк текста.
6) Переместить файл из одной директории в другую.
7) Скопировать файл из одной директории в другую.
8) Переименовать файл.
9) Сравнить содержимое двух файлов.
10) Отсортировать содержимое файла по возрастанию и убыванию.
11) Найти созданный файл по имени, не переходя вручную по всей структуре каталогов.
12) Удалить созданные в ходе задания файлы и каталоги.

## Критерий приёмки

В отчёте должны быть:
- команды, использованные для создания каталогов и файлов;
- итоговая структура созданных каталогов;
- команды перемещения, копирования и переименования файла;
- команда сравнения двух файлов и её результат;
- команды сортировки по возрастанию и убыванию;
- команда поиска файла по имени и результат;
- подтверждение удаления созданных в ходе задания объектов;
- краткое пояснение разницы между абсолютным и относительным путём.

# Практическая работа. Работа в консоли

## 1. Переместиться между директориями

Для перемещения из одной папки в другую используется команда `cd` (сокращение от **change directory**).

Путь может быть абсолютным и относительным.
*   **Абсолютный путь** начинается от корня системы или от домашней директории (символ `~`).
*   **Относительный путь** отсчитывается от текущего положения (например, `Documents` или `../Downloads`).
Выполнен переход из домашней директории (~) в папку Documents с использованием относительного пути. Затем командой cd .. осуществлен возврат обратно в домашнюю директорию ~ (абсолютный путь которой /Users/nasta).

## 5. Создание файла и запись в него нескольких строк

Для создания файла и записи в него текста прямо из терминала используется команда `printf`. Спецсимвол `\n` обозначает перенос строки (аналог нажатия клавиши Enter). Символ `>` (перенаправление вывода) записывает сгенерированный текст в указанный файл, а не выводит его на экран.

В папке third создан файл numbers.txt. В него записаны числа 5, 2, 8, 1 и 4, каждое с новой строки. Команда cat использована для проверки содержимого файла — она вывела записанные числа в консоль.

## 6. Перемещение файла между каталогами

Для перемещения файлов используется команда `mv` (move). Первым аргументом указывается исходный путь к файлу, вторым — новое место назначения.

Файл numbers.txt перемещен из глубоко вложенной папки third на два уровня выше — в корень папки practice. Исходный файл по старому пути удален.

## 7. Копирование файла в другой каталог
Для копирования файлов используется команда `cp` (copy). Она берет исходный файл и создает его точную копию по указанному новому пути, при этом оригинал остается на месте.

## 8. Переименование файла

Для переименования файла используется команда `mv`. Если исходный и конечный пути указывают на одну и ту же директорию, команда просто меняет имя файла.


Файл numbers_copy.txt, находящийся в папке first, переименован в data.txt. Папка осталась прежней, изменилось только имя файла. Терминал выполнил команду без вывода сообщений, что означает успех.

## 9. Сравнение содержимого двух файлов

Для построчного сравнения двух текстовых файлов используется `diff` (difference). Сначала создается второй файл с измененным содержимым (третье число заменено с 8 на 7), затем выполняется сравнение.

Создан файл numbers2.txt. diff сравнила его с numbers.txt и вывела результат 3c3. Это означает, что в третьей строке (3) произошло изменение (c — change). Символ < 8 указывает на содержимое первого файла, а > 7 — на содержимое второго.

## Абсолютный и относительный пути

Абсолютный путь — полный путь к файлу, начинающийся от корневого каталога файловой системы. Например: /Users/nasta/practice/numbers.txt.

Относительный путь — путь к файлу относительно текущего рабочего каталога. Например: practice/numbers.txt.

Таким образом, абсолютный путь указывает точное расположение файла в файловой системе, а относительный зависит от текущего каталога.
