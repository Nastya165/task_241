## 3. Что такое права доступа? Выведите права доступа на файлы в домашней директории одного из пользователей.

Права доступа — это механизм безопасности, определяющий, кто и какие действия может выполнять с файлом или каталогом. В Unix-системах права делятся на три категории (владелец, группа, остальные) и три типа действий (чтение r, запись w, выполнение x).

<img width="432" height="69" alt="image" src="https://github.com/user-attachments/assets/5b6b074e-8320-4a98-8aa6-0baf8eaeaab8" />

Сначала мы создали тестовый файл my_file.txt командой touch. Затем с помощью команды ls -l вывели подробную информацию о нем. В первой колонке отображаются права доступа: -rw-r--r--. Это значит, что - обозначает обычный файл, rw- позволяет владельцу (nasta) читать и записывать, r-- дает группе (staff) только право на чтение, и r-- оставляет остальным пользователям также только право на чтение.

## 5. Как называется встроенная учётная запись администратора в Linux?

Встроенная учётная запись администратора в Linux называется **`root`**. Она имеет идентификатор пользователя (UID) равный `0` и обладает максимальными правами на выполнение любых операций в системе. Вход под этой учетной записью обычно заблокирован в целях безопасности, а административные задачи выполняются через утилиту `sudo`.

## 6. Как выполнить одну команду с административными правами?

Для выполнения команд с правами администратора используется утилита **`sudo`** (superuser do). Она позволяет обычному пользователю временно получить права суперпользователя (`root`) для выполнения одной конкретной команды.

**Основные варианты использования `sudo`:**

1. **Запуск программы с правами root:**
   ```bash
   sudo имя_программы
Например, sudo ls /var/log выполнит команду ls от имени администратора, что позволит прочитать системные логи.

Запуск от имени другого пользователя:

   ```bash
sudo -u имя_пользователя команда
Например, sudo -u user1 ls выполнит команду ls так, как будто её ввел пользователь user1.
Отличие от команды su:

Также существует команда su (substitute user). Она позволяет временно переключиться на другого пользователя или стать суперпользователем (root) на всю сессию терминала.

  ```bash
su имя_пользователя
Чтобы стать root, обычно вводят su - (с дефисом), но для этого нужно знать пароль пользователя root.

Комбинированный вариант:
Иногда используют связку sudo su, чтобы, имея права на sudo (но не зная пароля root), переключиться в полноценную сессию суперпользователя:

  ```bash
sudo su
